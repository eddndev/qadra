# Reporte de Incidencias – Qadra

---

## 🐞 Problema 1: No es posible cambiar entre despachos

### Resumen del problema
Al tener más de un despacho no se puede acceder al anterior, ya que siempre se mantiene el último creado, lo que imposibilita cambiar de despacho.

### Pasos para replicar el error
1. Abrir la página de Qadra.  
2. Iniciar sesión.  
3. Seleccionar los despachos.  
4. Crear un nuevo despacho.  
5. Tratar de cambiar a un despacho anterior.

### Resultado actual
Solo se puede interactuar con el despacho más reciente.

### Resultado esperado
Poder cambiar entre despachos correctamente para gestionar toda la información necesaria.

---

## 🐞 Problema 2: Visualización incorrecta de expedientes entre despachos

### Resumen del problema
Se deben revisar las reglas de visualización de expedientes para determinar si deben mostrarse todos los expedientes de todos los despachos o solo los del despacho activo.

### Pasos para replicar el error
1. Entrar a la página de Qadra.  
2. Iniciar sesión.  
3. Ir a **Expedientes**.  
4. Crear un expediente.  
5. Cambiar de despacho.  
6. Crear un nuevo expediente.  
7. Observar la lista de expedientes.

### Resultado actual
Se muestran todos los expedientes sin importar el despacho al que pertenecen.  
- Los expedientes del despacho donde se crearon se abren correctamente.  
- Al intentar abrir un expediente de otro despacho, se produce un error.

### Resultado esperado
Mostrar únicamente los expedientes correspondientes al despacho activo.

## 🐞 Problema 3: Repetición del botón "Nueva evidencia"

### Resumen del problema
Dentro de un expediente, el botón **Nueva evidencia** aparece duplicado.

### Pasos para replicar el error
1. Entrar a la página de Qadra.  
2. Iniciar sesión.  
3. Ir a **Expedientes**.  
4. Abrir un expediente.  
5. Ir a la sección **Evidencia**.

### Resultado actual
Se muestran dos botones de **Nueva evidencia**, ambos funcionales.

### Resultado esperado
Mostrar un solo botón de **Nueva evidencia**.

---

## 🐞 Problema 4: Superposición de cuadros sobre la barra lateral

### Resumen del problema
Al ver un expediente, en las pestañas de **Documentos** y **Actuaciones (Bitácora)**, los cuadros para subir documentos o registrar actuaciones se sobreponen a la barra lateral izquierda.

### Pasos para replicar el error
1. Entrar a la página de Qadra.  
2. Iniciar sesión.  
3. Ir a **Expedientes**.  
4. Abrir un expediente.  
5. Ir a **Documentos** o **Actuaciones (Bitácora)**.  
6. Mover la barra de desplazamiento horizontal.

### Resultado actual
Algunos cuadros se sobreponen a la barra lateral del menú.

### Resultado esperado
Mantener un límite claro entre la barra lateral y el área de trabajo del expediente para evitar problemas visuales y asegurar una interfaz limpia y ordenada.
